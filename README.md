# 🍈 MELON AI (멜론 AI)
> 생성형 AI 음원 스트리밍 차트 & 아티스트 프로필 플랫폼

---

## 🌟 주요 핵심 기능

1. **멜론 시그니처 스트리밍 UI & 실시간 AI TOP 100 차트**
   - 멜론의 네온 그린(`Melon Green #00cd3c`)과 다크 글래스모피즘 테마.
   - 실시간 순위 변동 인디케이터 (`▲ 1`, `▼ 2`, `-`, `NEW`, `HOT`).
   - 장르별 필터(K-POP, EDM, Lo-Fi, Ballad) 및 AI 엔진별 필터(Suno, Udio).

2. **하단 고정형 멜론 글로벌 플레이어 (Sticky Bottom Player)**
   - 앨범 커버, 아티스트, AI 모델 태그, 실시간 가사 팝업, 재생 대기열(Queue Drawer).
   - 볼륨 슬라이더, 무한 루프 / 셔플 / 한 곡 반복 모드.
   - **사운드 보장 엔진 (Web Audio API)**: 실제 MP3 파일이 없어도 브라우저 자체 신디사이저 엔진으로 사운드 즉각 재생.

3. **AI 음원 발매 스튜디오 (Track Release Studio)**
   - 실제 Suno/Udio에서 생성한 오디오 파일(`MP3`, `WAV`, `OGG`, `M4A`) 드래그&드롭 업로드.
   - 곡명, 아티스트명, AI 프롬프트 태그, 가사, 앨범 커버 이미지 등록.
   - "멜론 차트에 즉시 발매" 클릭 시 실시간 TOP 100 차트 1위에 등록 및 자동 재생.

4. **아티스트 프로필 & 디스코그래피 (Artist Profile & My Music)**
   - 나만의 아티스트 활동명, 프로필 사진 업로드, Bio, 주력 AI 툴 배지.
   - 내가 발매한 곡 목록, 좋아요한 곡, 최근 재생곡 분리 관리.
   - 브라우저 `localStorage` 완벽 연동으로 새로고침해도 프로필과 음원 데이터 영구 보존.

---

## 🚀 빠른 실행 방법

### 방법 1. 더블 클릭으로 즉시 실행
- `start.bat` 파일을 더블 클릭하면 자동으로 웹 브라우저가 열리며 실행됩니다.

### 방법 2. 직접 열기
- `index.html` 파일을 크롬(Chrome)이나 엣지(Edge) 브라우저로 드래그하여 바로 실행할 수 있습니다.
