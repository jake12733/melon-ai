# 🚀 POLYSHIP AI MUSIC
> 독자적인 차세대 생성형 AI 음원 스트리밍 차트 & 아티스트 프로필 플랫폼

---

## 🌟 주요 핵심 기능

1. **폴리십 시그니처 스트리밍 UI & 실시간 AI TOP 100 차트**
   - 딥 코스믹 블랙 테마와 일렉트릭 퍼플(`Electric Purple #8b5cf6`) 포인트.
   - 실시간 AI TOP 100 음원 랭킹 및 장르별(K-POP, EDM, Lo-Fi, Cinematic) 실시간 필터링.
   - 하단 고정형 반응형 웹 오디오 플레이어 탑재.

2. **나만의 아티스트 프로필 커스텀 설정**
   - 프로필 사진 및 상단 와이드 배너 커버 업로드.
   - 아티스트 활동명, 고유 슬러그(@handle), 한 줄 소개(Bio), 대표 장르 설정.
   - 유튜브, 스레드, 인스타그램 크리에이터 소셜 링크 연동.
   - 브라우저 영구 보존 (`localStorage` 연동).

3. **4대 계정 & 클라우드 데이터베이스(DB) 연동 센터**
   - **구글 (Google)**: Google OAuth 2.0 / Firebase Auth 로그인 & 클라우드 백업.
   - **수노 (Suno)**: Suno 계정 연동 및 내 생성 AI 음원 라이브러리 원클릭 가져오기(Import).
   - **네이버 (Naver)**: 네이버 아이디로 로그인(Naver OAuth) & 국내 크리에이터 프로필 연동.
   - **카카오 (Kakao)**: 카카오톡 간편 연동(Kakao Sync) & 실시간 음원 카카오톡 공유.
   - **클라우드 DB 백엔드**: Supabase / PostgreSQL 스키마(`schema.sql`) 및 실시간 동기화 지원.

4. **AI 음원 발매 스튜디오 (Track Release Studio)**
   - 오디오 파일, 곡명, 생성 프롬프트, BPM/Key, 커버 이미지 등록.
   - 등록 즉시 "내 프로필 수록곡" 및 실시간 TOP 100 차트 1위 자동 발매.

5. **검색엔진 최적화 & 필수 정책 페이지 탑재**
   - 곡별 고유 상세 서브페이지 (`/track/dark-fantasy-boss-01.html` 등).
   - 다국어 URL 구조 (`/ko`, `/en`), `sitemap.xml`, `robots.txt`.
   - 4종 필수 정책 페이지 (개인정보처리방침, 이용약관, 상업용 라이선스 안내, 문의).

## 🚀 빠른 실행 방법

### 방법 1. 더블 클릭으로 즉시 실행
- `start.bat` 파일을 더블 클릭하면 자동으로 웹 브라우저가 열리며 실행됩니다.

### 방법 2. 직접 열기
- `index.html` 파일을 크롬(Chrome)이나 엣지(Edge) 브라우저로 드래그하여 바로 실행할 수 있습니다.
